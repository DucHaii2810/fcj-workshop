###  [Blog 1 - Exploring aws amplify: Why is it a great choice for personal projects or students assignments?](3.1-Blog1/)
This blog introduces AWS Amplify, a comprehensive toolset that enables developers to rapidly build full-stack web and mobile applications without managing complex cloud infrastructure. It highlights key features such as built-in authentication via Amazon Cognito, flexible GraphQL/REST API integration, and automated CI/CD hosting directly from GitHub or GitLab. This serverless solution eliminates server maintenance overhead, allowing students and developers to focus entirely on application logic and deliver MVPs efficiently.

###  [Blog 2 - What should you keep in mind when starting with AWS to avoid any "nasty surprises" on your end-of-month bill?](3.2-Blog2/)
This blog outlines essential cost-management practices to help AWS beginners prevent surprise charges from forgotten or idle cloud resources. It provides actionable steps including configuring AWS Budgets and Billing Alerts, understanding AWS Free Tier limits, cleaning up unattached EBS volumes or idle Elastic IPs, and monitoring usage via AWS Cost Explorer. Mastering these foundational financial controls ensures a safe and worry-free environment for cloud experimentation.

###  [Blog 3 - Building a simple, secure static website with S3 + cloudfront + route 53](3.3-Blog3/)
This blog presents a standardized serverless architecture for hosting and distributing static websites using Amazon S3, Amazon CloudFront, and Route 53. It walks through storing web assets in an S3 bucket, accelerating global delivery and enforcing HTTPS security via CloudFront with Origin Access Control (OAC), and routing custom domains with Route 53. This classic setup delivers high scalability, minimal operational maintenance, and near-zero hosting costs for personal and production web projects.
