Typically and as a standard practice, a worklog is carried out over about 3 months (throughout the internship period) with the weekly contents as follows:

**Week 1:** [Get acquainted with the FCAJ program, basic Cloud concepts, create an AWS account, install AWS CLI, and set up Budgets/Support](1.1-week1/)

**Week 2:** [Explore IAM, EC2, S3, practice cleaning up resources, and attend the talkshow "The Thinking Behind Building The Bot"](1.2-week2/)

**Week 3:** [Build a private network with VPC, compare RDS with DynamoDB, get familiar with Lambda, and attend AWS community events](1.3-week3/)

**Week 4:** [Practice in-depth with Lambda, API Gateway, DynamoDB, CloudWatch, and build a small serverless API](1.4-week4/)

**Week 5:** [Finalize the legal & security AI assistant topic under Decree 13/2023/ND-CP, choose serverless architecture, and write the Proposal draft](1.5-week5/)

**Week 6:** [Design the system prompt, context constraints, LegalArticles table schema on DynamoDB, and test question set](1.6-week6/)

**Week 7:** [Create the LegalArticles table on DynamoDB, load legal article data, and configure a least-privilege IAM role for Lambda](1.7-week7/)

**Week 8:** [Build and test the backend comprising Lambda, Groq API, and API Gateway, standardize error codes, and conduct security review](1.8-week8/)

**Week 9:** [Configure throttling, set up CloudWatch alarms, test prompt injection, review legal content, and estimate costs](1.9-week9/)

**Week 10:** [Build the chat interface on S3, perform end-to-end testing, finalize Proposal/Workshop/Worklog, and clean up resources](1.10-week10/)

**Week 11:** [Explore improvement directions for security, data retrieval, and monitoring, update Proposal/Workshop, and conduct final internship review](1.11-week11/)
