### Week 1 Objectives:

- Understand the fundamental concepts of cloud computing and the benefits of using the Cloud.
- Grasp AWS global infrastructure (Regions, Availability Zones, Data Centers, Edge Locations).
- Explore AWS management tools (Management Console, AWS CLI, SDK), cost optimization methods, and working with AWS Support.
- Create an AWS account, configure basic security settings, and set up administrative permissions.

### Achieved results of Week 1:

- Understood AWS's definition of cloud computing and its distinct advantages over traditional on-premises infrastructure.
- Mastered the structure of AWS's global network infrastructure, including regions, clusters of independent data centers, and content delivery networks.
- Distinguished between AWS management tools (Management Console, CLI, SDK) and grasped pricing models for cost optimization (On-Demand, Reserved Instances, Savings Plans, Spot).
- Successfully registered and activated a personal AWS account; learned how to resolve account, phone number, and payment card verification issues and create a Support Case when necessary.
- Completed account security configuration using Virtual MFA to protect the account.
- Became proficient in using IAM to create User Groups, assign Admin Policies, create IAM Users, and securely manage Access Keys.
- Learned how to set up AWS Budgets to configure cost and usage alert thresholds via Email, helping prevent unexpected charges during hands-on practice.
- Got familiar with self-evaluating system architectures through the AWS Well-Architected Framework.
