Thông thường và cũng là tiêu chuẩn, một worklog được thực hiện trong khoảng 3 tháng (trong suốt thời gian thực tập) với nội dung các tuần như sau:

**Tuần 1:** [Làm quen chương trình FCAJ, kiến thức Cloud cơ bản, tạo tài khoản AWS, cài AWS CLI và thiết lập Budgets/Support](1.1-week1/)

**Tuần 2:** [Tìm hiểu IAM, EC2, S3, thực hành dọn tài nguyên và tham dự talkshow "The Thinking Behind Building The Bot"](1.2-week2/)

**Tuần 3:** [Xây dựng mạng riêng với VPC, so sánh RDS với DynamoDB, làm quen Lambda và tham gia sự kiện cộng đồng AWS](1.3-week3/)

**Tuần 4:** [Thực hành chuyên sâu Lambda, API Gateway, DynamoDB, CloudWatch và xây dựng API serverless nhỏ](1.4-week4/)

**Tuần 5:** [Chốt đề tài trợ lý AI pháp lý & bảo mật theo Nghị định 13/2023/NĐ-CP, chọn kiến trúc serverless và viết bản nháp Proposal](1.5-week5/)

**Tuần 6:** [Thiết kế system prompt, ràng buộc ngữ cảnh, schema bảng LegalArticles trên DynamoDB và bộ câu hỏi kiểm thử](1.6-week6/)

**Tuần 7:** [Tạo bảng LegalArticles trên DynamoDB, nạp dữ liệu điều luật và cấu hình IAM role đặc quyền tối thiểu cho Lambda](1.7-week7/)

**Tuần 8:** [Xây dựng và kiểm thử backend gồm Lambda, Groq API và API Gateway, chuẩn hóa mã lỗi và rà soát bảo mật](1.8-week8/)

**Tuần 9:** [Cấu hình throttling, thiết lập CloudWatch alarm, kiểm thử prompt injection, rà soát pháp lý và ước tính chi phí](1.9-week9/)

**Tuần 10:** [Xây dựng giao diện chat trên S3, kiểm thử end-to-end, hoàn thiện Proposal/Workshop/Worklog và dọn dẹp tài nguyên](1.10-week10/)

**Tuần 11:** [Tìm hiểu hướng cải tiến bảo mật, truy xuất dữ liệu và giám sát, cập nhật Proposal/Workshop và rà soát cuối kỳ thực tập](1.11-week11/)
